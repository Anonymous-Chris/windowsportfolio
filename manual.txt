Dependency conflict recovery:
  1. Restore the package versions in package.json if npm has changed them:
     - echarts: ^5.4.1
     - react-file-viewer: ^1.2.1
     - react-router-dom: ^6.8.1
     - react-scripts: ^5.0.1
  2. Run:
     npm install --save-dev ajv@^8.17.1 --legacy-peer-deps
     npm install --legacy-peer-deps
  3. Verify the application:
     npm run build
  4. Start the development server:
     npm start

Do not use npm i --force or npm update to repair dependency conflicts unless
package.json and package-lock.json are first committed or backed up. For a
clean dependency install, remove node_modules and run the steps above again.
